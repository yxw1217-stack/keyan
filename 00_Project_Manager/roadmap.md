# Green CIL Project Roadmap

## 目标

开发具有低毒性、可降解性和高对映选择性的绿色手性离子液体及其复合材料，用于对映体识别与分离。

## 阶段

1. 文献调研与研究空白识别
2. 文献数据库与 CIL 分子数据库建立
3. 候选 CIL 结构设计
4. RDKit 描述符计算与结构相似性分析
5. 机器学习预测分离性能
6. DFT 与 Multiwfn 识别机制验证
7. CIL 膜材料与磁性 CIL 材料设计
8. 实验方案、分离测试与循环稳定性评价
9. 数据分析、图表生成与论文撰写
