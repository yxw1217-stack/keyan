# Green Chiral Ionic Liquids Research Project

本仓库用于开展绿色手性离子液体（Green Chiral Ionic Liquids, GCILs）及其衍生材料在对映体手性识别与分离中的科研工作。

## 项目结构

- `00_Project_Manager/`：项目管理与研究路线
- `01_Literature/`：文献与文献数据库
- `02_CIL_Database/`：CIL 分子数据库
- `03_RDKit/`：分子描述符与结构分析
- `04_ML_Model/`：分离性能预测模型
- `05_DFT/`：ORCA 与 Multiwfn 理论计算
- `06_MD/`：LAMMPS 分子动力学模拟
- `07_Experiment/`：实验方案与操作规程
- `08_Data_Analysis/`：HPLC、GC、CE 数据分析
- `09_Figures/`：论文级图表
- `10_Manuscript/`：论文稿件与补充材料

## 数据与可复现性

原始数据、处理脚本、分析结果和论文图表应分别归档，并记录版本、参数和运行环境。
